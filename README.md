# SearchWorker

Сервис для автоматического поиска вакансий, подходящих под резюме пользователя.

Пользователь загружает своё резюме, а сервис:

1. Собирает вакансии с нескольких job-площадок (HH.ru, Хабр Карьера, HireHi и др.)
2. Сопоставляет вакансии с резюме по навыкам, должности, грейду и зарплатной вилке
3. Отправляет новые подходящие вакансии в Telegram

**Стек:** Go, PostgreSQL, Docker, Telegram Bot API

**Архитектура:** гексагональная (чистая архитектура)
